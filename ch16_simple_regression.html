Chapter 16　簡單線性迴歸分析

迴歸分析（Regression Analysis）是統計學中最廣泛應用的工具之一，目的是找出一個或多個自變數（X）與依變數（Y）之間的數量關係。本章聚焦於簡單線性迴歸（Simple Linear Regression）——只有一個自變數的情形。我們將從母體模型出發，學習如何用樣本資料估計迴歸線，並進行統計推論與預測。

🎯 Learning Objectives

  • 理解母體迴歸模型 $Y = \beta_0 + \beta_1 X + \varepsilon$ 的結構與假設條件（LINE）。
  • 能應用最小平方法（OLS）估計迴歸係數 $b_0, b_1$，並理解估計值與母體參數的差異。
  • 能分解總變異（SST = SSR + SSE），計算 $R^2$ 衡量模型的解釋力。
  • 能對 $\beta_1$ 進行 t 檢定，判斷 X 對 Y 是否有顯著的線性影響。
  • 能建立迴歸 ANOVA 表，以 F 檢定驗證整體模型顯著性（在簡單迴歸中 $F = t^2$）。
  • 能區分平均值信賴區間（CI）與個別預測區間（PI），並理解兩者的寬度差異。
  • 能進行基本殘差分析，檢驗迴歸模型的假設是否成立。

Section 16.1　母體迴歸模型

在研究兩個變數之間的關係時，我們先假設存在一個真實的母體關係，然後用樣本去估計它。

📐 母體迴歸模型（Population Regression Model）

$$Y = \beta_0 + \beta_1 X + \varepsilon$$
  • $\beta_0$：母體截距（Population Intercept）——真實參數，未知
  • $\beta_1$：母體斜率（Population Slope）——真實參數，未知
  • $\varepsilon$：誤差項（Error Term）——代表所有其他未被 X 解釋的因素及隨機波動

關鍵概念：$\beta_0$ 和 $\beta_1$ 是固定的（雖然未知的）母體參數，就像 $\mu$ 和 $\sigma$。我們用樣本估計值 $b_0$（估 $\beta_0$）和 $b_1$（估 $\beta_1$）來逼近它們，但估計值不等於真值。

✅ 誤差項的假設條件（LINE）

  1. L — Linearity（線性）：$Y$ 與 $X$ 之間存在線性關係，即 $E(Y|X) = \beta_0 + \beta_1 X$
  2. I — Independence（獨立）：各觀測值的誤差項 $\varepsilon_i$ 彼此獨立
  3. N — Normality（常態性）：誤差項服從常態分配，$\varepsilon \sim N(0, \sigma^2)$
  4. E — Equal Variance（變異數齊性）：對所有 $X$ 值，誤差項的變異數均相等（Homoscedasticity）

📝 主範例　缺席次數與出席成績：從母體到樣本

情境：假設「缺席次數（$X$）」與「出席成績（$Y$）」之間存在以下真實的母體關係： $$Y = \underbrace{95}_{\beta_0} + \underbrace{(-6)}_{\beta_1} \cdot X + \varepsilon, \quad \varepsilon \sim N(0, \sigma^2)$$ 這表示：平均而言，缺席一次成績下降 6 分；若從未缺席（$X=0$），預期平均成績為 95 分。

然而在現實中，我們不知道 $\beta_0 = 95$ 和 $\beta_1 = -6$。我們只能從樣本資料去估計它們。

Section 16.2　最小平方估計（OLS）

現在我們假裝不知道 $\beta_0, \beta_1$ 的真值，純粹用 15 筆樣本資料去估計。

最小平方法（Ordinary Least Squares, OLS）的核心思想：找一條直線，使得所有樣本點到這條直線的垂直距離平方和最小。

📐 OLS 估計公式

$$b_1 = \frac{S_{xy}}{S_{xx}} = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2}$$
$$b_0 = \bar{y} - b_1 \bar{x}$$

估計迴歸線（Estimated Regression Line）：$\hat{y} = b_0 + b_1 x$

殘差（Residual）$e_i = y_i - \hat{y}_i$：樣本觀測值與估計值之差。注意殘差 $e_i$ 是誤差項 $\varepsilon_i$ 的估計，但兩者不同——$\varepsilon_i$ 是真實誤差（未知），$e_i$ 是可計算的樣本殘差。

📝 主範例（續）　用 15 筆樣本估計迴歸線

Step 1 — 計算樣本平均數

$$\bar{x} = \frac{4+3+0+\cdots+2}{15} = \frac{50}{15} = 3.333, \quad \bar{y} = \frac{74+72+92+\cdots+79}{15} = \frac{1114}{15} = 74.267$$

Step 2 — 計算 $S_{xx}$ 與 $S_{xy}$

$$S_{xx} = \sum(x_i - \bar{x})^2 = (4-3.333)^2+(3-3.333)^2+\cdots = 77.333$$
$$S_{xy} = \sum(x_i - \bar{x})(y_i - \bar{y}) = (4-3.333)(74-74.267)+\cdots = -408.333$$

Step 3 — 計算 $b_1, b_0$

$$b_1 = \frac{S_{xy}}{S_{xx}} = \frac{-408.333}{77.333} = -5.280, \quad b_0 = 74.267 - (-5.280)(3.333) = 91.867$$

估計迴歸線：

$$\hat{y} = 91.867 - 5.280\, x$$

🌐 母體（真實，未知）

📊 樣本估計（可計算）

$\beta_0 = 95$

$\beta_1 = -6$

$Y = 95 - 6X + \varepsilon$

$b_0 = 91.867 \approx \beta_0$

$b_1 = -5.280 \approx \beta_1$

$\hat{y} = 91.867 - 5.280\,x$

✅ 樣本估計值 $b_0 = 91.867$（真值 95）、$b_1 = -5.280$（真值 −6）——接近但不完全相等，這正是抽樣誤差造成的。不同的樣本會得到不同的 $b_0, b_1$，但當樣本數夠大時，估計值會趨向真值。這就是為什麼增加樣本數能提高估計精度。

Section 16.3　$\sigma$ 的估計與 $R^2$

變異分解：SST = SSR + SSE

迴歸分析的核心邏輯是：Y 的總變異可以被分解為「迴歸可解釋的部分」與「殘差（無法解釋的部分）」。

📐 三大平方和

$$\underbrace{\text{SST}}_{\text{Total}} = \underbrace{\text{SSR}}_{\text{Regression}} + \underbrace{\text{SSE}}_{\text{Error}}$$
$$\text{SST} = \sum(y_i - \bar{y})^2, \quad \text{SSR} = \sum(\hat{y}_i - \bar{y})^2, \quad \text{SSE} = \sum(y_i - \hat{y}_i)^2 = \sum e_i^2$$

決定係數 $R^2$（Coefficient of Determination）：

$$R^2 = \frac{\text{SSR}}{\text{SST}} = 1 - \frac{\text{SSE}}{\text{SST}} \in [0, 1]$$

誤差標準差 $s_e$（Standard Error of Estimate）：

$$s_e = \sqrt{\text{MSE}} = \sqrt{\frac{\text{SSE}}{n-2}}$$

$s_e$ 是母體誤差標準差 $\sigma$ 的估計，自由度為 $n-2$（估計了兩個參數 $b_0, b_1$）。
$R^2$ 的解讀：$R^2 = 0.80$ 表示自變數 X 解釋了 Y 總變異的 80%，剩餘 20% 由其他未納入的因素或隨機誤差造成。

Section 16.4　t 檢定：斜率係數的顯著性

我們想知道：$X$ 對 $Y$ 是否真的有線性影響？這等同於問：母體斜率 $\beta_1$ 是否顯著不等於 0？

$H_0: \beta_1 = 0$（X 對 Y 沒有線性影響）
$H_1: \beta_1 \neq 0$（X 對 Y 有線性影響）

📐 斜率的 t 檢定

$b_1$ 的標準誤：

$$s_{b_1} = \frac{s_e}{\sqrt{S_{xx}}} = \sqrt{\frac{\text{MSE}}{S_{xx}}}$$

t 統計量：

$$t = \frac{b_1 - 0}{s_{b_1}} = \frac{b_1}{s_{b_1}} \sim t_{n-2}$$

$\beta_1$ 的信賴區間：

$$b_1 \pm t_{\alpha/2,\; n-2} \cdot s_{b_1}$$

$b_0$ 亦可類似地進行推論，其標準誤為 $s_{b_0} = s_e\sqrt{\dfrac{1}{n}+\dfrac{\bar{x}^2}{S_{xx}}}$，但實務上截距的顯著性通常較不重要。

📝 主範例（續）　對 $\beta_1$ 進行 t 檢定（$\alpha = 0.05$）

Step 1 — 假設：$H_0: \beta_1 = 0$；$H_1: \beta_1 \neq 0$

Step 2 — 計算

$$s_{b_1} = \sqrt{\frac{\text{MSE}}{S_{xx}}} = \sqrt{\frac{8.374}{77.333}} = 0.329$$
$$t = \frac{b_1}{s_{b_1}} = \frac{-5.280}{0.329} = -16.046$$

Step 3 — 決策：$df = n - 2 = 13$，$t_{0.025, 13} = 2.160$

$|t| = 16.046 > 2.160$，p 值 $\approx 0.000$ → 強力拒絕 $H_0$

$\beta_1$ 的 95% 信賴區間：

$$-5.280 \pm 2.160 \times 0.329 = -5.280 \pm 0.711 = (-5.991,\; -4.569)$$

✅ 缺席次數對出席成績有極為顯著的負向線性影響（p ≈ 0）。我們有 95% 的信心相信：每多缺席一次，出席成績平均下降 4.57 到 5.99 分之間。

💡 信賴區間的解讀：此區間完全落在負值，進一步確認缺席次數對成績有顯著的負面影響，與母體真值 $\beta_1 = -6$ 非常接近（但稍高），符合抽樣誤差的預期。

📝 輔助範例（續）　研發支出 → 營收：對 $\beta_1$ 進行 t 檢定（$\alpha = 0.05$）

沿用 16.2、16.3 的結果：$b_1 = 7$，$S_{xx} = 10$，$\text{SSE} = 110$，$n = 5$。

Step 1 — 假設：$H_0: \beta_1 = 0$；$H_1: \beta_1 \neq 0$

Step 2 — 計算

$$\text{MSE} = \frac{\text{SSE}}{n-2} = \frac{110}{3} = 36.667, \quad s_e = \sqrt{36.667} = 6.055$$
$$s_{b_1} = \sqrt{\frac{\text{MSE}}{S_{xx}}} = \sqrt{\frac{36.667}{10}} = 1.915$$
$$t = \frac{b_1}{s_{b_1}} = \frac{7}{1.915} = 3.656$$

Step 3 — 決策：$df = n - 2 = 3$，$t_{0.025,\, 3} = 3.182$

$|t| = 3.656 > 3.182$ → 拒絕 $H_0$

$\beta_1$ 的 95% 信賴區間：

$$7 \pm 3.182 \times 1.915 = 7 \pm 6.093 = (0.907,\; 13.093)$$

✅ 研發支出對營收有顯著的正向線性影響（$\alpha = 0.05$）。但注意此範例 $n = 5$ 極小，$df = 3$ 使得臨界值高達 3.182，信賴區間也相當寬（0.907 到 13.093）——樣本數不足時，即使結果顯著，估計精度仍然有限。

Section 16.5　F 檢定：迴歸 ANOVA 表

除了 t 檢定，迴歸模型的整體顯著性也可以用 F 檢定（透過迴歸 ANOVA 表）來驗證。

F 檢定的假設：從「模型解釋力」出發

F 檢定的出發點與 t 檢定不同。t 檢定問的是「某個係數是否為零」；F 檢定問的是「這個迴歸模型整體上對 Y 有沒有解釋能力」——也就是說，把 X 納入模型之後，能不能顯著地減少 Y 的預測誤差？

F 檢定假設：
$H_0$：迴歸模型對 $Y$ 不具有解釋能力（X 無法解釋 Y 的變異）
$H_1$：迴歸模型對 $Y$ 具有解釋能力（X 能顯著解釋 Y 的變異）

在簡單線性迴歸中的等價關係：
「模型無解釋能力」等價於「唯一的解釋變數斜率為零」，因此 $H_0$ 等價於 $\beta_1 = 0$。
然而到了複迴歸（Chapter 17），F 檢定的 $H_0$ 是「所有係數 $\beta_1 = \beta_2 = \cdots = 0$」，而 t 檢定則分別針對每個係數——兩者不再等價，各有獨立的檢定目的。

F 統計量的直覺：解釋的變異 vs 未解釋的變異

F 統計量的核心邏輯是比較兩種變異的比值：

📐 迴歸 ANOVA 表與 F 統計量

來源SSdfMSF
迴歸（Regression）SSR1MSR = SSR/1$F = \dfrac{\text{MSR}}{\text{MSE}}$
誤差（Error）SSE$n-2$MSE = SSE/$(n-2)$
總計（Total）SST$n-1$

直覺上：$F$ 越大，表示「迴歸能解釋的變異（MSR）」相對於「殘餘誤差（MSE）」越大，模型的解釋力越強。若 $H_0$ 為真（模型毫無解釋力），則 MSR 與 MSE 應相近，$F \approx 1$。

拒絕域：$F$ 檢定為右尾檢定（解釋力過強才拒絕 $H_0$），拒絕域為 $F > F_{\alpha,\, 1,\, n-2}$。
簡單迴歸中的等價性：可以數學上證明 $F = t^2$，因此 F 檢定與 t 檢定的結論完全一致。但此等價性在複迴歸中消失。

$H_1$：迴歸模型對出席成績具有解釋能力（缺席次數能顯著解釋成績變異；等價於 $\beta_1 \neq 0$）

📝 輔助範例（續）　研發支出 → 營收：F 檢定（$\alpha = 0.05$）

沿用前各節結果：$\text{SSR} = 490$，$\text{SSE} = 110$，$\text{SST} = 600$，$n = 5$。

Step 1 — 假設

$H_0$：迴歸模型對年營收不具有解釋能力（研發支出無法解釋營收變異；等價於 $\beta_1 = 0$）
$H_1$：迴歸模型對年營收具有解釋能力（研發支出能顯著解釋營收變異；等價於 $\beta_1 \neq 0$）

Step 2 — 建立拒絕域

$df_1 = 1$，$df_2 = n - 2 = 3$，查表得 $F_{0.05,\, 1,\, 3} = 10.128$。
拒絕域：$F > 10.128$

迴歸490149013.364≈ 0.035

$$F = \frac{\text{MSR}}{\text{MSE}} = \frac{490}{36.667} = 13.364$$

Step 4 — 決策

$F = 13.364$ 落在拒絕域（$> 10.128$），p 值 $\approx 0.035$ → 拒絕 $H_0$

Step 5 — 驗證等價性

$$F = 13.364 \approx 3.656^2 = t^2 \checkmark$$

💡 t 檢定 vs F 檢定的切入角度：
・t 檢定（16.4）：「研發支出的斜率係數 $\beta_1$ 是否顯著不為零？」→ $t = 3.656 > t_{0.025,3} = 3.182$，拒絕 $H_0$。
・F 檢定（16.5）：「這個模型整體上對營收有沒有解釋能力？」→ $F = 13.364 > F_{0.05,1,3} = 10.128$，拒絕 $H_0$。
・兩者結論一致，且 $F = t^2$（$13.364 \approx 3.656^2$）。在簡單迴歸中「某個係數不為零」與「模型有解釋力」是同一件事；但在 Chapter 17 的複迴歸中，這兩個問題將是獨立的——屆時 F 檢定成為驗證「整體模型是否有意義」的專屬工具。

Section 16.6　預測：信賴區間 vs 預測區間

有了迴歸線，我們可以對新的 $x^*$ 值進行預測。但「預測的不確定性」有兩種，對應兩種不同的區間：

🔵 平均值信賴區間（CI for Mean Response）

問題：「所有缺席 $x^*$ 次的學生，平均成績的範圍？」

$$\hat{y} \pm t_{\alpha/2,n-2} \cdot s_e \sqrt{\frac{1}{n}+\frac{(x^*-\bar{x})^2}{S_{xx}}}$$

估計的是 $E(Y|X=x^*)$ 的位置，較窄。

🟠 個別預測區間（PI for Individual）

問題：「某一位缺席 $x^*$ 次的學生，這個人的成績範圍？」

$$\hat{y} \pm t_{\alpha/2,n-2} \cdot s_e \sqrt{1+\frac{1}{n}+\frac{(x^*-\bar{x})^2}{S_{xx}}}$$

除了平均值的不確定外，還加上個別誤差 $\varepsilon$，較寬。

關鍵差異：PI 比 CI 多了一個 「$1$」在根號下，代表個別觀測值的隨機誤差 $\sigma^2$。CI 的寬度可以隨 $n \to \infty$ 縮為 0，但 PI 即使 $n \to \infty$ 也不會縮為 0（因為個別誤差永遠存在）。

📝 主範例（續）　預測缺席 3 次的學生成績（$\alpha = 0.05$）

$x^* = 3$，$\hat{y} = 91.867 - 5.280 \times 3 = 76.027$

$$h = \frac{1}{n}+\frac{(x^*-\bar{x})^2}{S_{xx}} = \frac{1}{15}+\frac{(3-3.333)^2}{77.333} = 0.0667+0.00144 = 0.0681$$

🔵 平均值 95% CI

$$76.027 \pm 2.160 \times 2.894 \times \sqrt{0.0681}$$ $$= 76.027 \pm 1.630$$ $$= (74.40,\; 77.66)$$

缺席 3 次的學生，平均成績介於 74.40–77.66 分

🟠 個別預測 95% PI

$$76.027 \pm 2.160 \times 2.894 \times \sqrt{1+0.0681}$$ $$= 76.027 \pm 6.460$$ $$= (69.57,\; 82.49)$$

某一位缺席 3 次的學生，個人成績介於 69.57–82.49 分

✅ CI 寬度約 3.3 分，PI 寬度約 12.9 分，PI 遠寬於 CI。這反映出：預測個別學生比預測「平均學生」有更大的不確定性——即使我們對迴歸線的估計已經非常準確，個別學生的表現仍受各種隨機因素影響。

Section 16.7　殘差分析

迴歸模型的假設條件（LINE）需要透過殘差分析（Residual Analysis）來驗證。殘差 $e_i = y_i - \hat{y}_i$ 應表現出隨機性，若有系統性規律則表示假設被違背。

📊 四種殘差圖及其判斷標準

1. 殘差 vs 配適值圖（$e_i$ vs $\hat{y}_i$）

✅ 正常：殘差隨機散佈在 0 附近，無明顯規律
❌ 問題：呈漏斗狀 → 變異數不齊性（Heteroscedasticity）
❌ 問題：呈弧形 → 非線性關係，應考慮曲線迴歸

2. 殘差 vs X 值圖（$e_i$ vs $x_i$）

✅ 正常：殘差隨機散佈，無趨勢
❌ 問題：有系統趨勢 → 線性假設可能不成立
❌ 問題：變異隨 X 增大 → 變異數不齊性

3. 殘差常態機率圖（Normal Q-Q Plot）

✅ 正常：殘差接近對角線，呈直線
❌ 問題：S 形或彎曲 → 誤差不服從常態分配

4. 殘差 vs 時間/序號圖

✅ 正常：無系統性循環或趨勢
❌ 問題：有週期性規律 → 誤差項不獨立（自相關）

  1. Ex 1　年資與月薪（基本 OLS 與 t 檢定）

    人力資源部門想瞭解員工年資（$X$，年）是否能預測月薪（$Y$，千元）。隨機抽取 6 位員工資料如下：

    年資 $x$345723
    月薪 $y$（千元）324047463645

    a. 計算 OLS 估計迴歸線 $\hat{y} = b_0 + b_1 x$。

    b. 計算 $R^2$ 並解釋其意義。

    c. 在 $\alpha = 0.05$ 下，對 $\beta_1$ 進行 t 檢定，判斷年資對月薪是否有顯著線性影響。

    d. 討論：$R^2$ 偏低代表什麼含義？

    ▶ 點此展開解答

    Part (a)　$\bar{x}=4, \bar{y}=41$

    $$S_{xx}=\sum(x_i-4)^2=(3-4)^2+(4-4)^2+(5-4)^2+(7-4)^2+(2-4)^2+(3-4)^2=1+0+1+9+4+1=16$$ $$S_{xy}=\sum(x_i-4)(y_i-41)=(-1)(-9)+(0)(-1)+(1)(6)+(3)(5)+(-2)(-5)+(-1)(4)=9+0+6+15+10-4=36$$ $$b_1=\frac{36}{16}=2.25,\quad b_0=41-2.25\times4=32$$ $$\hat{y}=32+2.25\,x$$

    Part (b)

    $$\text{SST}=(-9)^2+(-1)^2+6^2+5^2+(-5)^2+4^2=81+1+36+25+25+16=184$$ $$\text{SSR}=b_1 \cdot S_{xy}=2.25\times36=81, \quad \text{SSE}=184-81=103$$ $$R^2=\frac{81}{184}=0.440$$

    年資僅解釋了月薪變異的 44.0%，配適度偏低。

    Part (c)　$df = n-2 = 4$，$t_{0.025,4} = 2.776$

    $$\text{MSE}=\frac{103}{4}=25.75,\quad s_{b_1}=\sqrt{\frac{25.75}{16}}=1.269,\quad t=\frac{2.25}{1.269}=1.773$$

    $|t|=1.773 < 2.776$，p 值 $\approx 0.151 > 0.05$ → 不拒絕 $H_0$

    ❌ 在 $\alpha=0.05$ 下，沒有充分的統計證據推論年資對月薪有顯著線性影響。

    Part (d) 討論：$R^2 = 0.44$ 偏低，且 $\beta_1$ 不顯著，表示：

    • 年資以外的因素（職位、學歷、部門、績效等）對月薪有更大的解釋力
    • 樣本數 $n=6$ 非常小，統計力（Power）低，即使效果存在也可能無法偵測
    • 若要更可靠的結論，需要更大的樣本，或引入更多變數（複迴歸）

    研究者蒐集 10 組男性成年子女的父母平均身高（$X$，公分）與子女身高（$Y$，公分）資料：

    父母平均 $x$162164166168170170172174176178
    子女身高 $y$170168174172176176176182180186

    a. 計算迴歸線 $\hat{y} = b_0 + b_1 x$，並解釋 $b_1$ 的含義。

    b. 計算 $R^2$，說明配適度。

    c. 在 $\alpha = 0.05$ 下，$\beta_1$ 是否顯著？（$t_{0.025,8} = 2.306$）

    d. 預測：父母平均身高 175 公分的家庭，男性子女身高的點估計為何？

    ▶ 點此展開解答

    Part (a)　$n=10$，$\bar{x} = 1700/10 = \mathbf{170}$，$\bar{y} = 1760/10 = \mathbf{176}$

    $$S_{xx} = (-8)^2+(-6)^2+(-4)^2+(-2)^2+0^2+0^2+2^2+4^2+6^2+8^2 = 240$$ $$S_{xy} = (-8)(170-176)+(-6)(168-176)+\cdots+(8)(186-176)$$ $$= (-8)(-6)+(-6)(-8)+(-4)(-2)+(-2)(-4)+(0)(0)+(0)(0)+(2)(0)+(4)(6)+(6)(4)+(8)(10) = 240$$ $$b_1 = \frac{240}{240} = \mathbf{1.000}, \quad b_0 = 176 - 1.000 \times 170 = \mathbf{6}$$ $$\hat{y} = 6 + 1.000\,x$$

    $b_1$ 的解釋：父母平均身高每增加 1 公分，男性子女身高預期增加 1.00 公分（等於母體真值）。

    Part (b)

    $$\text{SST} = 6^2+8^2+2^2+4^2+0^2+0^2+0^2+6^2+4^2+10^2 = 272$$ $$\text{SSR} = b_1 \cdot S_{xy} = 1.000 \times 240 = 240, \quad \text{SSE} = 272-240 = 32$$ $$R^2 = \frac{240}{272} = 0.882$$

    父母平均身高解釋了子女身高變異的 88.2%，配適度高。

    Part (c)

    $$\text{MSE} = \frac{32}{8} = 4, \quad s_e = \sqrt{4} = 2, \quad s_{b_1} = \frac{s_e}{\sqrt{S_{xx}}} = \frac{2}{\sqrt{240}} = 0.1291$$ $$t = \frac{1.000}{0.1291} = 7.746, \quad df=8, \quad t_{0.025,8}=2.306$$

    $|t| = 7.746 \gg 2.306$ → 強力拒絕 $H_0$，父母平均身高對子女身高有極顯著影響。

    Part (d)　$\hat{y} = 6 + 1.000 \times 175 = \mathbf{181}$ 公分

    ✅ 身高遺傳效應顯著（$p \approx 0$）。此例 $b_1 = 1.000$ 剛好等於母體真值——這是巧合（抽樣設計使然），實務上估計值與真值不會完全相同。$s_e = 2$ 公分表示典型預測誤差約 ±2 公分。

  3. Ex 3　CAPM 市場模型（$\beta$ 係數估計）

    Capital Asset Pricing Model（CAPM）的市場模型為：

    $$R_i = \alpha + \beta \cdot R_m + \varepsilon$$

    其中 $R_m$ 為市場月報酬率（%），$R_i$ 為個股月報酬率（%），$\beta$ 衡量個股對市場波動的敏感度（$\beta > 1$ 為積極型股票）。以下為某科技股連續 12 個月的資料（整數，便於計算）：

    月份123456789101112
    市場 $R_m$−3−2−1011223342
    個股 $R_i$−2−31020425753

    a. 估計市場模型，求 $\hat{\alpha}$（$b_0$）和 $\hat{\beta}$（$b_1$）。（提示：$\bar{R}_m = 1$，$\bar{R}_i = 2$，$S_{xx} = 50$）

    b. 計算 $R^2$，說明市場因子對個股報酬的解釋力。

    c. 在 $\alpha = 0.05$ 下，$\beta$ 是否顯著？說明此股票特性。（$t_{0.025,10} = 2.228$）

    d. 解釋 $\hat{\alpha}$ 在 CAPM 中的經濟意涵。

    ▶ 點此展開解答

    Part (a)　$n=12$，$\bar{R}_m = 12/12 = \mathbf{1}$，$\bar{R}_i = 24/12 = \mathbf{2}$，$S_{xx} = \mathbf{50}$

    $$S_{xy} = \sum(R_{m,i}-1)(R_{i,i}-2) = (-4)(-4)+(-3)(-5)+(-2)(-1)+(-1)(-2)+0+(-1)(0-2)+\cdots = 63$$
    $$\hat{\beta} = b_1 = \frac{S_{xy}}{S_{xx}} = \frac{63}{50} = 1.26, \quad \hat{\alpha} = b_0 = 2 - 1.26 \times 1 = 0.74$$ $$\hat{R}_i = 0.74 + 1.26\, R_m$$

    Part (b)

    $$\text{SST} = 98,\quad \text{SSR} = b_1 \cdot S_{xy} = 1.26 \times 63 = 79.38,\quad \text{SSE} = 18.62$$ $$R^2 = \frac{79.38}{98} = 0.810$$

    市場因子解釋了個股報酬率變異的 81.0%，市場系統性風險是此股票報酬的主要驅動力。

    Part (c)

    $$\text{MSE} = \frac{18.62}{10} = 1.862,\quad s_{b_1} = \sqrt{\frac{1.862}{50}} = 0.193$$ $$t = \frac{1.26}{0.193} = 6.53,\quad df=10,\quad t_{0.025,10}=2.228$$

    $|t| = 6.53 \gg 2.228$ → 強力拒絕 $H_0$

    $\hat{\beta} = 1.26 > 1$：此股票為積極型股票（Aggressive Stock），市場每上漲 1%，此股票預期上漲 1.26%；市場每下跌 1%，此股票預期下跌 1.26%，系統性風險高於大盤。

    Part (d) $\hat{\alpha}$ 的經濟意涵：

    $\hat{\alpha} = 0.74\%$：在控制市場因子後，此股票平均每月仍有 0.74% 的「超額報酬」（Jensen's Alpha）。CAPM 理論預測 $\alpha = 0$（市場完全有效），$\hat{\alpha} > 0$ 暗示此股票可能被低估或具有非系統性優勢，對投資者是正面訊號。

    ✅ $\hat{\beta} = 1.26$ 顯著大於 1，適合風險偏好型投資人。$R^2 = 0.81$ 顯示除市場因子外，仍有約 19% 的個股特有風險（公司特定事件等）無法被市場因子解釋。

母體模型$Y=\beta_0+\beta_1 X+\varepsilon$$\beta_0,\beta_1$ 未知；$\varepsilon\sim N(0,\sigma^2)$；LINE 假設
OLS 估計$b_1=S_{xy}/S_{xx}$，$b_0=\bar{y}-b_1\bar{x}$$b_0\approx\beta_0$，$b_1\approx\beta_1$，差距來自抽樣誤差
變異分解SST = SSR + SSE$R^2=\text{SSR}/\text{SST}$，$s_e=\sqrt{\text{MSE}}$，$df=n-2$
t 檢定$t=b_1/s_{b_1}\sim t_{n-2}$$H_0:\beta_1=0$；$s_{b_1}=s_e/\sqrt{S_{xx}}$
F 檢定（ANOVA）$F=\text{MSR}/\text{MSE}$簡單迴歸：$F=t^2$，等價；複迴歸：不再等價
CI（平均值）$\hat{y}\pm t\cdot s_e\sqrt{h}$估計 $E(Y|X=x^*)$ 的區間，較窄
PI（個別）$\hat{y}\pm t\cdot s_e\sqrt{1+h}$預測個別觀測值，永遠比 CI 寬
殘差分析$e_i=y_i-\hat{y}_i$檢驗 LINE；漏斗→異方差；弧形→非線性
  • 母體 vs 樣本：$\beta_0, \beta_1$ 是未知的真值；$b_0, b_1$ 是從樣本估計的，因抽樣誤差而與真值有差距。
  • $R^2$ 的限制：高 $R^2$ 不代表因果關係；低 $R^2$ 不一定代表關係不重要（也可能是非線性或樣本小）。
  • 簡單 vs 複迴歸的分岔點：在簡單迴歸中 $F = t^2$，兩種檢定完全等價；在複迴歸中，t 檢定是個別係數的檢定，F 檢定是整體模型的檢定，兩者獨立且都不可省略。
  • PI > CI 永遠成立：根號下多一個「1」，個別預測的不確定性永遠大於平均值估計。
