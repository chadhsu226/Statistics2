χ² 卡方分配（Chi-Square Distribution）
定義：若 Z₁, Z₂, …, Zᵥ 為 ν 個獨立的標準常態隨機變數，則其平方和
χ²(ν) = Z₁² + Z₂² + … + Zᵥ² = Σᵢ Zᵢ²
所服從的分配稱為自由度 ν 的卡方分配，記作 χ²(ν)。

基本性質

定義域
χ² ≥ 0（僅非負值）
平均數 E(χ²)
= ν（自由度）
變異數 Var(χ²)
= 2ν
眾數（Mode）
= max(ν−2, 0)
形狀
右偏；ν 小時偏斜大
累加性
χ²(m)+χ²(n) ~ χ²(m+n)
ν → ∞ 時
趨近常態分配
與常態關係
Z² ~ χ²(1)

密度函數（PDF）

f(x; ν) = x^(ν/2−1) · e^(−x/2) / [ 2^(ν/2) · Γ(ν/2) ] ，x > 0
其中 Γ(·) 為 Gamma 函數；自由度 ν 決定曲線的形狀與集中程度。

常見應用場景

① 推論母體變異數：以樣本變異數 S² 推論母體 σ² 時，檢定統計量 (n−1)S²/σ₀² 服從 χ²(n−1)。

② 適合度檢定（Goodness-of-fit test）：檢定觀測次數是否符合理論分配。

③ 獨立性檢定（列聯表 Contingency Table）：判斷兩個類別變數是否獨立。

④ 同質性檢定：比較多個母體的比例是否相同。

表 卡方分配表（右尾臨界值）
右尾機率 P(χ² > χ²α,ν) = α，表格中的數值為臨界值 χ²α,ν。
查表步驟：① 確認自由度 ν（列）→ ② 選定顯著水準 α（欄）→ ③ 交叉格即為臨界值。
χ²₀.₀₅, ν=5 = 11.070
F F 分配（F Distribution）
定義：若 χ²(d₁) 與 χ²(d₂) 為兩個獨立的卡方隨機變數，則其比值
F(d₁, d₂) = [ χ²(d₁) / d₁ ] / [ χ²(d₂) / d₂ ]
所服從的分配稱為分子自由度 d₁、分母自由度 d₂ 的 F 分配，記作 F(d₁, d₂)。

基本性質

定義域
F ≥ 0（僅非負值）
平均數 E(F)
= d₂ / (d₂ − 2)，d₂ > 2
形狀
右偏；自由度大趨近對稱
倒數關係
1/F(d₁,d₂) ~ F(d₂,d₁)
與 t 的關係
t²(ν) = F(1, ν)
與卡方的關係
由兩個 χ² 比值構成
左尾臨界值
F₁₋α,d₁,d₂ = 1/Fα,d₂,d₁
常見應用
ANOVA、比較兩母體變異數

密度函數（PDF）

f(x; d₁,d₂) = √[ (d₁x)^d₁ · d₂^d₂ / (d₁x+d₂)^(d₁+d₂) ] / [ x · B(d₁/2, d₂/2) ]，x > 0
其中 B(·,·) 為 Beta 函數。分子/分母自由度各別決定曲線的偏斜程度。

與 ANOVA（變異數分析）的關聯

在單因子 ANOVA 中，檢定統計量為：

F = MST / MSE = SST/(k−1) / SSE/(n−k)

其中 MST 為處理間均方（分子自由度 = k−1），MSE 為誤差均方（分母自由度 = n−k）。若 F 落入右尾拒絕域（F > Fα,k−1,n−k），則拒絕 H₀，推論各組平均數間存在顯著差異。

表 F 分配表（右尾臨界值）
右尾機率 P(F > Fα,d₁,d₂) = α，表格欄為分子自由度 d₁，列為分母自由度 d₂。
查表步驟：① 選定 α → ② 找分子自由度欄（d₁）→ ③ 找分母自由度列（d₂）→ ④ 交叉格即為 Fα。
F₀.₀₅, d₁=5, d₂=10 = 3.33
查表注意事項

① 左尾臨界值：F1−α, d₁, d₂ = 1 / Fα, d₂, d₁（互換分子分母自由度後取倒數）。

② 若表中無精確的自由度，可取較保守（較大）的臨界值，或利用線性內插法估算。

③ 雙尾檢定（比較兩母體變異數）時，以 α/2 查表。
